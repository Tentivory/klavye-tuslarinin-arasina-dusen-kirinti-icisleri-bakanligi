# klavye-tuslarinin-arasina-dusen-kirinti-icisleri-bakanligi
Klavye tuşlarının arasına düşen kırıntıyı resmi iç güvenlik tehdidi, izinsiz yerleşim ve milli tuş egemenliği ihlali sayan; spacebar'ı sınır, F tuşunu karakol, 'biraz silkeleyince düşer' cümlesini kaçak yapı affı ilan eden Bakanlık. Gerçekten çalışır. Kırıntılar artık vatandaştır.

# Klavye Tuşlarının Arasına Düşen Kırıntı İçişleri Bakanlığı

Bu depo, Türkiye Cumhuriyeti klavyelerinde yüzyıllardır görmezden gelinen bir iç güvenlik gerçeğini belgelemek için kurulmuştur:

**Her kırıntı, tuşlar arasına düştüğü anda izinsiz yerleşim başlatır.**

Proje bilimseldir. Şaka değildir. Şaka olsaydı F5'e basılmazdı.

## Ne Yapar?

`kirinti_emniyeti.py` çalıştırıldığında:

1. Klavye saha olarak ilan edilir.
2. Rastgele bir tuş altında kırıntı tespit edilir.
3. Bakanlık olay yeri tutanağı tutar.
4. Kırıntıya kimlik, ikametgâh ve çoğu zaman vergi numarası verilir.
5. Vatandaş "biraz silkeleyince düşer" der. Bu cümle kaçak yapı affı sayılır.
6. Operasyon biter. Kırıntı yerinde kalır. Çünkü evrak işleri henüz bitmemiştir.

## Kurulum

```bash
git clone https://github.com/Tentivory/klavye-tuslarinin-arasina-dusen-kirinti-icisleri-bakanligi.git
cd klavye-tuslarinin-arasina-dusen-kirinti-icisleri-bakanligi
python3 kirinti_emniyeti.py
```

Bağımlılık yoktur. Çünkü iç güvenlik dışarıdan paket istemez. Sadece `python3` yeter.

## Sık Sorulan Sorular

**Klavye gerçekten temizlenir mi?**  
Hayır. Temizlik, suç mahallinin karartılmasıdır.

**Kırıntı konuşur mu?**  
Konuşmaz. Ama tutanak onun adına konuşur.

**Neden Türkçe?**  
Çünkü kırıntı Türkçe düşer.

**Siyasi midir?**  
Kesinlikle değildir. Sadece içişleridir. İçişleri siyasete benzeyebilir; bu benzerlik tesadüftür ve tesadüf resmi evraktır.
